# Security

Do not attach real desktop snapshots, decrypted `--private-details` output, access tokens or private folder paths to a public issue.

Report vulnerabilities privately through GitHub's private vulnerability reporting when enabled. If unavailable, open a public issue requesting a private contact without disclosing exploit details or sensitive data.

Current-user DPAPI protects data at rest against other ordinary users; it is not a defense against malware running as the same user or an administrator. The tool does not collect browser credentials or upload data. The user controls screenshot capture and recovery.
